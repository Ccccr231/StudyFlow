# StudyFlow：大学生学习与生活 Agent

2026-10-25 更新：两个 AI 入口已统一使用按账号加密保存的个人 DeepSeek/OpenAI 配置，支持替换和移除密钥；其余工具预算、资料隔离和用户审批边界延续本文设计。最新交付状态见 [PROGRESS.md](PROGRESS.md)。

日期：2026-10-20。产品目标：以课程为依据，结合个人学习表现和真实日程，持续帮助大学生学习、安排生活并执行可审阅的行动。

## 架构决策

保留 Next.js 模块化单体、本地账号、Prisma 数据库、当前 DeepSeek 兼容接入口、角色与剧情。新增一个有界工具循环，不另建多 Agent 平台或引入编排框架。

浏览器 → 身份/同源/输入校验 → 会话运行器 → 模型选择工具 → 服务端执行白名单工具 → 结果返回模型 → 回答或等待用户输入。每轮有次数、时间和输出预算，拒绝无限执行。运行器保存会话和工具记录，刷新可以继续。

教学资料先进入本地资料库，保留来源和位置，再检索相关片段提供给模型。它是检索增强，不修改底层模型权重，不宣称完成模型训练。初期关键词检索在单用户有限资料内工作；后续以召回评测结果决定是否增加向量检索。

个人记录保存用户原话和具体证据，模型的学习观察标记为待验证，不直接当成成绩或掌握结论。生活管理先使用已有任务/计划能力承接报名、采购、运动等待办；精确课表、通知推送、外部校园系统接入另行建设。

## 数据库 Schema 增量

- `StudyMaterial`：id、userId、title、subject、createdAt；关联多个 `MaterialChunk`。
- `MaterialChunk`：id、materialId、position、locator、text。来源位置来自实际导入内容，不能由模型编造。
- `AgentConversation`：id、userId、title、updatedAt、运行租约；关联消息。
- `AgentMessage`：id、conversationId、role、content、trace、createdAt。trace 保存实际工具结果和引用信息。
- `LearningObservation`：id、userId、conversationId、topic、observation、evidence、createdAt；属于模型观察，用户可查看和删除。

所有读写从服务端会话取得 userId，关联记录再次校验归属。数据库升级只添加表和关系，不重置原始账号、任务、剧情或素材。

## 第一阶段验收范围

1. 用户导入自己的课程文字资料，列出/读取/删除，提取位置可追溯。
2. 持久化会话、读取学习概况、检索资料、依据资料讲解和追问。
3. 模型可记录有当前用户原话依据的待验证学习观察；下次继续时可读取，用户可删除。
4. 模型通过原有白名单提出学习和生活待办/计划，仍需用户确认才执行。
5. 工具调用结果反馈模型，重复调用有预算、并发有保护，失败有明确记录。
6. 真实数据库/接口/浏览器测试与真实云模型验收分别记录；受控模型响应不能当成云模型成功。

## 后续路线与明确边界

- 阶段二：PDF/扫描件/公式解析质量评测、课程章节和前置关系、经过校验的题库、分步作答及间隔复测。首版不凭模型自评分数宣布掌握。
- 阶段三：课表、考试和截止时间、冲突检测、用户可控的通知；生活待办从按日安排升级到具体时间段。
- 阶段四：在取得实际文档和授权后接入校园系统/日历，不模拟官方连接，不擅自发送消息或替用户提交事务。
- 阶段五：积累经审核的教学示范，建立独立评测集，再判断是否值得微调；不自动把用户资料或聊天用于训练。

## 调研依据

- https://api-docs.deepseek.com/guides/tool_calls/ ：模型返回工具调用，应用执行并以 tool_call_id 回传结果。
- https://github.com/anthropics/courses/tree/master/tool_use ：借鉴完整工具反馈循环，不复制其服务商依赖。
- https://github.com/run-llama/llama_index ：借鉴文档分段和来源保留；首版复用本项目数据库实现。
- https://www.anthropic.com/engineering/contextual-retrieval ：分段需保留文档上下文，以实际检索评测决定升级方案。

## 数据与费用

资料导入和本地检索不调用云模型。用户点击发送时，输入、必要的当前学习概况、最近会话及检索片段会发送到当前配置的模型服务，消耗该账号额度；页面应明确展示这一点。开发验收优先使用自写的非私人材料，真实云调用次数与结果单独记录。
