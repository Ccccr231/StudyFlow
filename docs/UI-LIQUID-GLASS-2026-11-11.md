# 校园液态玻璃界面 · 2026-11-11

沿用原有校园场景、林连理立绘和学习功能，增强玻璃界面的透明度、亮边、内高光及柔和阴影。桌面导航改为浮动面板，数据卡片、专注区、任务筛选、日期选择、Agent 面板、迎宾对话、登录和任务弹窗使用统一玻璃样式。

## 折射与可读性

- 引入 liquid-glass-web 技能附带的零依赖 `liquid-glass.js` 引擎，保留其跨引擎滤镜兼容处理。
- `GlassBackdrop` 仅折射与校园场景对齐的装饰副本；正文和原生控件独立渲染，装饰不接收点击、不进入无障碍树。
- 姓名牌、侧栏寄语、统计卡片、专注卡片及登录面板使用 SVG 背景折射。顶栏、普通面板和弹窗使用 CSS 毛玻璃；各浏览器的背景模糊效果可能有差异。
- 滚动时只调整背景位置；卸载时清理滤镜、监听与观察器。高对比度或减少透明度偏好会切换实色衬底并关闭折射。
- 手机端调整首页横幅文字区域，避免文字在人物上方挤成单字行。
